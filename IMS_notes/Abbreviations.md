# Abbreviations Dictionary (IMS)

## A
- **A2A** = Application-to-Application
- **A2P** = Application-to-Person
- **ACK** = Acknowledgement (SIP)
- **AG** = Access Gateway
- **AGCF** = Access Gateway Control Function
- **AKA** = Authentication and Key Agreement
- **ALG** = Application Layer Gateway
- **AO** = Application Originated
- **AS** = Application Server
- **ASA/ASR** = Abort-Session-Answer / -Request
- **AT** = Application Terminated
- **ATCF** = Access Transfer Control Function
- **ATS** = Application Trigger Server

## B
- **BGF** = Border Gateway Function
- **BRA** = Basic Rate Access
- **BSS** = Business Support System (billing/provisioning)
- **BYE** = SIP method to end a session

## C
- **CCF** = Charging Collection Function
- **CN** = Core Network
- **CSCF** = Call Session Control Function
   - **P-CSCF** = Proxy Call Session Control Function
   - **I-CSCF** = Interrogating Call Session Control Function
   - **S-CSCF** = Serving Call Session Control Function
   - **E-CSCF** = Emergency Call Session Control Function
- **CS** = Circuit Switched
- **CUDB** = Central User Database

## D
- **DHCP** = Dynamic Host Configuration Protocol
- **DNS** = Domain Name System
- **DPR/DPA** = Disconnect-Peer-Request / -Answer

## E
- **EMA** = Ericsson Multi Activation
- **EMM** = Ericsson Multi Mediation
- **EMS** = Element Management System
- **ENUM** = Electronic Numbering
- **EPS** = Evolved Packet System
- **ESME** = External Short Messaging Entity
- **ETSI** = European Telecommunications Standards Institute

## G
- **GGSN** = Gateway GPRS Support Node
- **GIBA** = GPRS IMS Bundled Authentication
- **GPRS** = General Packet Radio Service
- **GSM** = Global System for Mobile Communications
- **GSMA** = GSM Association

## H
- **HLR** = Home Location Register
- **HSS** = Home Subscriber Server
   - **SLF** = Subscription Locator Function
   - **CUDB** = Central User Database
- **HTTP** = HyperText Transfer Protocol

## I
- **IAD** = Integrated Access Device
- **IBCF** = Interconnection Border Control Function
- **IETF** = Internet Engineering Task Force
- **IM** = IP Multimedia
- **IMSI** = International Mobile Subscriber Identity
- **IMS** = IP Multimedia Subsystem
   - **IMS-AKA** = IMS Authentication and Key Agreement
- **INVITE** = SIP method to start a session
- **IP** = Internet Protocol
- **IPSec** = Internet Protocol Security
- **ISIM** = IP Multimedia Services Identity Module
- **ISC** = IMS Service Control
- **ISUP** = ISDN User Part

## L
- **LTE** = Long Term Evolution

## M
- **M2M** = Machine-to-Machine
- **MAP** = Mobile Application Part
- **MGC** = Media Gateway Controller
- **MGCF** = Media Gateway Control Function
- **MGCP** = Media Gateway Control Protocol
- **MGW** = Media Gateway
   - **M-MGW** = Multimedia Media Gateway
- **MME** = Mobility Management Entity
- **MMS** = Multimedia Messaging Service
- **MNO** = Mobile Network Operator
- **MO** = Mobile Originated
- **MSAN** = Multi-Service Access Node
- **MSISDN** = Mobile Station International Subscriber Directory Number
- **MSRP** = Media Session Relay Protocol
- **MT** = Mobile Terminated
- **MTAS** = Multimedia Telephony Application Server
- **MRF** = Media Resource Function
   - **MRFC** = Media Resource Function Controller
   - **MRFP** = Media Resource Function Processor

## N
- **NAT** = Network Address Translation
- **NBA** = NASS Bundled Authentication
- **NASS** = Network Access Server Subsystem
- **NPDB** = Number Portability Database

## O
- **OCS** = Online Charging System
- **OMA** = Open Mobile Alliance
- **OSS** = Operation Support System
- **OSS/BSS** = Operation/Business Support System
- **OTT** = Over-The-Top

## P
- **P2A** = Person-to-Application
- **P2P** = Person-to-Person
- **PBX** = Private Branch Exchange
- **PCRF** = Policy and Charging Rules Function
- **PDN-GW** = Packet Data Network Gateway
- **PGW** = Packet Data Network Gateway
- **PLMN** = Public Land Mobile Network
- **POTS** = Plain Old Telephone Service
- **PS** = Packet Switched
- **PSDN** = Public Switched Data Network
- **PSTN** = Public Switched Telephone Network

## Q
- **QCI** = QoS Class Identifier
- **QoS** = Quality of Service

## R
- **RCS** = Rich Communication Services
- **Rf/Ro** = Charging interfaces (Rf offline, Ro online)
- **RTP** = Real-time Transport Protocol

## S
- **SBG** = Session Border Gateway
   - **A-SBG** = Access Session Border Gateway
   - **N-SBG** = Network Session Border Gateway
- **SBC** = Session Border Controller (generic; IMS uses SBG)
- **SDP** = Session Description Protocol
- **SGW** = Serving Gateway
- **SIM** = Subscriber Identity Module
- **SIM OTA** = SIM Over-The-Air
- **SIP** = Session Initiation Protocol
- **SLA** = Service Level Agreement
- **SMSC** = Short Message Service Center
- **SOAP** = Simple Object Access Protocol
- **SPC** = Stored Program Control
- **SPN** = Service Provider Name

## T
- **TDM** = Time Division Multiplexing
- **TISPAN** = Telecoms and Internet converged Services and Protocols for Advanced Networking
- **TPS** = Transactions Per Second

## U
- **UA** = User Agent
- **UAC/UAS** = User Agent Client / Server
- **UAAF** = User Access Authorization Function
- **USSD** = Unstructured Supplementary Service Data
- **USIM** = Universal Subscriber Identity Module

## V
- **VAS** = Value-Added Services
- **VoLTE** = Voice over LTE
- **VMS** = Voice Mail System

## X
- **XML** = Extensible Markup Language

## 3
- **3GPP** = 3rd Generation Partnership Project

## Diameter (commands)
- **ASR/ASA** = Abort-Session-Request / -Answer
- **ACR/ACA** = Accounting-Request / -Answer
- **CER/CEA** = Capabilities-Exchange-Request / -Answer
- **DWR/DWA** = Device-Watchdog-Request / -Answer
- **DPR/DPA** = Disconnect-Peer-Request / -Answer
- **RAR/RAA** = Re-Auth-Request / -Answer
- **STR/STA** = Session-Termination-Request / -Answer
- **UAR/UAA** = User-Authorization-Request / -Answer
- **SAR/SAA** = Server-Assignment-Request / -Answer
- **LIR/LIA** = Location-Info-Request / -Answer
- **MAR/MAA** = Multimedia-Auth-Request / -Answer
- **RTR/RTA** = Registration-Termination-Request / -Answer
- **PPR/PPA** = Push-Profile-Request / -Answer
